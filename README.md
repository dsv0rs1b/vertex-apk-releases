## На телефоне

1. Нажми на ссылку нужного приложения в таблице выше
2. Скачай APK → открой в «Загрузках»
3. Разреши установку из браузера (неизвестные источники)
4. Войди тем же email, что на [vertexecosystem.vercel.app](https://vertexecosystem.vercel.app)
